# Safe installation
Extract the seven coordination Markdown files into a temporary folder first. Do not blindly replace existing AGENTS.md or README.md. Ask the local agent to inspect git status and merge the new rules/overview with existing project-specific setup, phase documentation and conventions. Keep existing files, migrations and implementation unchanged. Place the seven merged files in the repository root (or preserve established doc locations and update references consistently). Verify links and phase status against local evidence; if Phase 6.1 has already progressed, retain verified progress. Report the diff before starting implementation. INSTALL.md is optional and need not be copied into the project.
